## How to Add My Next Case Study

My next case study will be added to the **Selected Projects** section of my personal portfolio, with a dedicated case-study page for the full project story.

I will follow the same three-part structure:

1. **Problem** — Clearly explain the user or business problem the project was designed to solve.
2. **What I Did** — Describe my role, process, design decisions, frontend work, AI work, and the main features I built.
3. **What Came of It** — Show the final result, key outcomes, important features, and what I learned.

### Steps to Add a New Case Study

1. Add the project information to `data/profile.ts`.
2. Add the project's images/screenshots to the appropriate folder inside `public`.
3. Add the project card to the Selected Projects section.
4. Create a dedicated case-study page for the project.
5. Test the project locally with `npm run dev`.
6. Commit and push the changes to GitHub.
7. Verify that Vercel has successfully deployed the updated portfolio.
